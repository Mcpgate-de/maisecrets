# Norwegian (Bokmål) credential labels.
# Fields, tab-separated: a lowercase literal every match contains, the regex, examples.
# (?<![^\W\d_]) is the start of a word: no letter of any script before it, while _ and a digit may
# stand there (db_...). The sources of every word: docs/label-sources.md.
# passord: no word start, because Norwegian joins compounds (adminpassord). The English pass
# takes passord at a word start already.
passord	passord	passord, Passord, db_passord, nytt passord
# nøkkel alone is an ordinary word (key): only the compounds and the two-word labels count.
kkel	(?<![^\W\d_])(?:hemmelig[ _-]|tilgangs|api[ _-]?)n(?:ø|oe?)kkel	hemmelig nøkkel, Hemmelig nokkel, tilgangsnøkkel, API-nøkkel, api_noekkel
hemmelighet	(?<![^\W\d_])klient[ _-]?hemmelighet	klient-hemmelighet, Klienthemmelighet
loggingsdetaljer	(?<![^\W\d_])p(?:å|aa?)loggingsdetaljer	påloggingsdetaljer, Paaloggingsdetaljer
